# Online Church Design Variants

Static English-language website previews for a U.S. online church.

## Variants

- `warm-digital-parish/` - warm, pastoral, community-first church site.
- `modern-worship-broadcast/` - cinematic livestream-first worship site.
- `mission-discipleship-platform/` - structured discipleship and next-steps platform.

Open `index.html` to compare all three variants.

## GitHub Pages

The Pages workflow publishes this directory as a static site:

```text
.github/workflows/pages.yml
```

Publishing surface: GitHub Pages.
Publish directory: `site-variants`.
Build command: none; the site is static HTML/CSS.
Published URL: `https://ringaiengaipaeikag.github.io/online-church-design-variants/`.
